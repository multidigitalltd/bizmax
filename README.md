# Bizmax – תבנית וורדפרס

תבנית ייעודית לאתר **ביזמקס** (מרכז החדשנות והעסקים החרדי, ירושלים), בנויה לפי תקן הפיתוח של Multi Digital:
רזה, מאובטחת, נגישה (WCAG 2.2 AA / ת"י 5568), ללא ספריות צד ג', ותואמת LiteSpeed Cache / Cloudflare / Redis / Elementor.

## מה יש בתבנית (שלב 1)

| רכיב | איך זה עובד |
|---|---|
| **הידר + פוטר** | גלובליים לכל האתר – גם בעמודי אלמנטור קיימים. תפריטים מוורדפרס, לוגו מה-Customizer. |
| **דף הבית** | תבנית עמוד `דף הבית – ביזמקס`. **כל התוכן נערך מלוח הבקרה** ונשמר בתוך הדף עצמו (post meta), לא "הלבשה" קבועה. |
| **שאר האתר** | `page.php` מציג את תוכן העמוד כפי שהוא – עמודי אלמנטור מוצגים ללא שינוי, עם ההידר והפוטר של התבנית. |
| **טופס יצירת קשר** | REST + Nonce (נטען דינמית – עובד גם מאחורי Cache), Honeypot, בדיקת זמן, Rate-Limit, ולידציה מלאה בצד השרת, שליחה ב-`wp_mail`. |

## התקנה

1. העתיקו את התיקייה ל-`wp-content/themes/bizmax` והפעילו את התבנית.
2. בהפעלה הראשונה התבנית יוצרת אוטומטית (רק אם לא קיימים): עמוד **"דף הבית"** עם התבנית, תפריט ראשי ותפריטי פוטר עם הקישורים מהעיצוב, טיוטת **"הצהרת נגישות"** וטיוטת **"מדיניות הפרטיות"**.
   אם לאתר כבר מוגדר עמוד ראשי – ההגדרה לא נדרסת; הגדירו ידנית ב-**הגדרות → קריאה**.
3. **עיצוב → התאמה אישית → "ביזמקס – פרטי קשר ופוטר"**: טלפון, וואטסאפ, מייל, כתובת, הטמעת מפה, מייל לקבלת פניות. הלוגו – תחת "זהות האתר".
4. **עיצוב → תפריטים**: מיקומים `תפריט ראשי`, `תפריט המבורגר` (אם ריק – משתמש בראשי), `פוטר – עמודה 1/2`.

## עריכת דף הבית

עמודים → "דף הבית" → תיבת **"תוכן דף הבית"** עם לשוניות לכל מקטע:
הירו · המתחם · דה-סקול · ביזלאבס · מרחב צמיחה · יומן פעילות · אודות · הבוגרים מספרים · השותפים · עוד בביזמקס + טופס.

- לכל מקטע יש "הצגת המקטע" (אפשר להסתיר).
- תמונות נבחרות מספריית המדיה; אם לא נבחרה תמונה – מוצגת תמונת ברירת המחדל מהעיצוב.
- אירועים / תחנות / המלצות / שותפים הם **חזרות (Repeater)** עם הוספה, הסרה ושינוי סדר.
- ביומן פעילות אפשר לסמן "הסתרה אוטומטית של אירועים שתאריכם עבר".
- שדות "פסקה" מקבלים מעברי שורה ו-HTML בסיסי (`b`, `a`, `br`).

כדי להפוך עמוד אחר לדף הבית של התבנית: מאפייני עמוד → תבנית → "דף הבית – ביזמקס" → שמירה.
(בעמוד כזה עורך התוכן הרגיל מוסתר – כל התוכן בשדות.)

הוק למפתחים: `bizmax_home_content` (סינון התוכן לפני רינדור, למשל הזנת אירועים מ-CPT) ו-`bizmax_contact_submitted` (חיבור CRM/Webhook אחרי פנייה תקינה).

## אלמנטור

- עמודי אלמנטור עובדים כרגיל עם התבנית "ברירת מחדל" או "Elementor Full Width" – שתיהן מקבלות את ההידר והפוטר של התבנית.
- עמודים שמוגדרים **"Elementor Canvas"** מוצגים תמיד ללא ההידר והפוטר של התבנית (וללא כפתור הוואטסאפ). אלמנטור מציג אותם בתבנית ריקה משלו, והתבנית מוסיפה הגנה משלה: גם אם עמוד Canvas מגיע מסיבה כלשהי לקבצי התבנית (למשל אלמנטור מושבת או תוסף שמחליף תבניות), `header.php` ו-`footer.php` לא מציגים דבר. ניתן להרחיב דרך המסנן `bizmax_hide_header_footer`.
- התבנית רושמת ל-Theme Builder רק מיקומי `single` ו-`archive`, כך שההידר והפוטר נשארים תמיד של התבנית.
- הגופן **Ploni** זמין בבורר הגופנים של אלמנטור (קבוצת "ביזמקס").

## DeSchool – מערכת הקורסים (מובנית בתבנית)

מגרסה 1.2.0 התבנית כוללת את כל הפונקציונליות של התוסף **DeSchool** (md-deschool 1.17.0), ואין צורך בתוסף נפרד.
הקוד נמצא ב-`modules/deschool/` והוא זהה לקוד התוסף. השינוי היחיד הוא טעינת התרגומים מתיקיית התבנית. לכן כל הנתונים והממשקים נשארים בדיוק כפי שהיו:

- סוגי תוכן: `mdds_unit` (יחידות/קורסים, בכתובת `/unit/`) ו-`mdds_chapter` (פרקים).
- שדות מטא: כל המפתחות `_mdds_*` של יחידות ופרקים, ונתוני המשתמשים `_mdds_completed_chapters`, `_mdds_task_answers`, `_mdds_quiz_results`.
- שורטקודים: `[deschool_account]`, `[deschool_courses]`, `[deschool_dashboard]`, `[deschool_course id="…"]`.
- נקודת הקצה `/learn/`, פעולות ה-AJAX (`mdds_save_answers`, `mdds_mark_complete`, `mdds_submit_quiz`, `mdds_qa_post`), האשף, ייצוא התשובות, שאלות ותשובות, אזור אישי, ושילוב WooCommerce.
- אפשרויות: `mdds_account_page_id`, `mdds_courses_page_id`, `mdds_rewrite_version`. המסננים `mdds_use_single_template` ו-`mdds_user_has_access` נשמרו, וכך גם האפשרות לעקוף תבניות דרך `md-deschool/…` בתבנית-בת.

**מעבר מהתוסף:**
1. מעדכנים את התבנית לגרסה 1.2.0 ומעלה. כל עוד התוסף פעיל, הוא ממשיך לנהל הכול, והעותק שבתבנית לא נטען. בלוח הבקרה תוצג הודעה שאפשר להשבית את התוסף.
2. משביתים את התוסף DeSchool במסך התוספים. מהבקשה הבאה התבנית מפעילה את המודול עם אותם נתונים, ומרעננת פעם אחת את כללי הכתובות של `/unit/` ו-`/learn/`.
3. אפשר למחוק את התוסף. המחיקה מסירה רק אפשרות ישנה אחת (`mdds_demo_unit_id`) שאינה בשימוש, והקורסים וההתקדמות לא נפגעים.

אין להפעיל שוב את התוסף כשהתבנית פעילה. וורדפרס יסרב להפעיל אותו עם הודעת שגיאה, כי הקוד כבר טעון מהתבנית.
נכסי ה-CSS/JS של המודול נטענים רק בעמודי הקורסים, כמו בתוסף. מספר הגרסה שלהם נגזר מגרסת התבנית, ולכן כל עדכון של התבנית מרענן גם אותם במטמון.

## ביצועים ואבטחה

- CSS/JS נטענים מותנה: `main` בכל האתר, `home` רק בדף הבית; JS ב-`defer`; גרסאות `.min` נטענות אוטומטית (ב-`SCRIPT_DEBUG` – המקור).
- גופני Ploni מקומיים עם `font-display: swap` ו-preload לשני המשקלים שמעל הקיפול; תמונות ברירת מחדל ב-WebP; `loading="lazy"` לכל מה שמתחת לקיפול, `fetchpriority="high"` ל-LCP.
- תוכן דף הבית בשורת meta אחת (שאילתה אחת, בתוך ה-cache של הפוסט). ללא טבלאות, ללא autoload כבד.
- Sanitization לפי סכימה בשמירה, Escaping בכל פלט, Nonce + `current_user_can` בשמירה, `permission_callback` ב-REST, `wp_safe_redirect` בלבד, אין `eval/base64`.
- **Cloudflare Turnstile בטופס יצירת קשר:** כשהתוסף Simple Cloudflare Turnstile פעיל ומוגדרים בו מפתחות, מוצג אימות Cloudflare מעל כפתור השליחה. השרת מאמת את האסימון דרך פונקציית התוסף אחרי בדיקת השדות ולפני שליחת המייל. לכן שליחה ישירה ל-REST בלי אימות נדחית (403), ושום מייל לא נשלח. העיצוב, השפה, המראה, רשימת ה-IP הלבנה ומצב הגיבוי (failsafe) נלקחים מהגדרות התוסף. אפשר לכבות את האימות בטופס דרך Customizer ← "ביזמקס – פרטי קשר ופוטר". בלי התוסף, הטופס עובד כרגיל.
- Schema.org Organization מוזרק בדף הבית רק אם אין תוסף SEO (Yoast / Rank Math / AIOSEO).

## נגישות

דילוג לתוכן, H1 יחיד, היררכיית כותרות, ניווט מקלדת מלא (מגירה עם לכידת פוקוס, ESC והחזרת פוקוס), תוויות לכל שדה, שגיאות טופס מקושרות (`aria-describedby`), אזור חי לקרוסלה ולסטטוס הטופס, `prefers-reduced-motion` מכבה את כל האנימציות.
סטיות קטנות מהעיצוב לטובת ניגודיות AA: טקסט כתום קטן על לבן (`#9a5f08` במקום `#F6A81C`), ריחוף על כפתור משני – טקסט כחול על כתום (במקום לבן על כתום), placeholder כהה יותר.

יש להשלים את עמוד **"הצהרת נגישות"** (נוצר כטיוטה) ולפרסמו – הקישור מופיע אוטומטית בפוטר ובתפריט הנגישות.

### תפריט נגישות מובנה

כפתור נגישות צף בכל עמודי האתר (כולל עמודי אלמנטור ו-Canvas) פותח חלון עם ההתאמות:
גודל טקסט (100%–200%, פועל גם על תוכן אלמנטור), ניגודיות גבוהה, רקע בהיר, גווני אפור, הדגשת קישורים, הדגשת כותרות, גופן קריא, ריווח טקסט (WCAG 1.4.12), עצירת אנימציות (כולל וידאו ו-sliders), סמן עכבר גדול, הדגשת מיקוד מקלדת, איפוס, וקישור להצהרת הנגישות.

- **נגישות התפריט עצמו:** `<dialog>` מודאלי מקורי – לכידת פוקוס, סגירה ב-ESC או בלחיצה מחוץ לחלון, החזרת הפוקוס לכפתור, `aria-pressed` לכל מתג, הכרזה בקורא מסך על כל שינוי, ניווט מקלדת מלא, RTL/LTR. הכפתור הוא הרכיב השני בסדר ה-Tab, מיד אחרי "דלג לתוכן". axe-core: 0 הפרות, גם עם החלון פתוח וגם במצבי הניגודיות.
- **ביצועים ומטמון:** JavaScript טהור, ללא ספריות, `defer`. כ-9KB CSS וכ-5KB JS (מוקטנים). ההגדרות נשמרות ב-`localStorage` של הגולש בלבד – השרת מחזיר HTML זהה לכולם, ולכן התפריט עובד מאחורי LiteSpeed Cache, Cloudflare ו-Redis בלי חריגות. סקריפט קטן ב-`<head>` מחיל את ההגדרות לפני הציור הראשון, בלי הבהוב.
- **הגדרות:** עיצוב ← התאמה אישית ← **"ביזמקס – נגישות"**: הצגה/הסתרה של הכפתור, מיקום (ימין למטה, או שמאל למטה מעל כפתור הוואטסאפ), ובחירת עמוד הצהרת הנגישות.
- **שימו לב:** התפריט הוא כלי עזר. הוא לא מחליף את הנגישות של התוכן עצמו (טקסט חלופי לתמונות, כותרות, ניגודיות בעמודי אלמנטור), שבאחריות עורכי התוכן.

## פיתוח

```
assets/css/main.css   סגנונות גלובליים (הידר, פוטר, כפתורים, עמודים רגילים)
assets/css/home.css   דף הבית בלבד
assets/js/main.js     מגירת תפריט נגישה
assets/js/home.js     reveal, סיבוב הפרח, מונים, קרוסלה, טופס
inc/home-schema.php   הסכימה של דף הבית: מקטעים → שדות → ברירות מחדל (מקום אחד לכל שדה)
inc/home-content.php  קריאה / סניטציה / ברירות מחדל
inc/home-admin.php    תיבת העריכה (לשוניות, מדיה, repeaters)
inc/contact-form.php  REST של הטופס
template-parts/home/  המקטעים
```

מיניפיקציה (לאחר עריכת CSS/JS):

```
npx esbuild assets/css/main.css --minify --outfile=assets/css/main.min.css
npx esbuild assets/css/home.css --minify --outfile=assets/css/home.min.css
npx esbuild assets/js/main.js   --minify --target=es2017 --outfile=assets/js/main.min.js
npx esbuild assets/js/home.js   --minify --target=es2017 --outfile=assets/js/home.min.js
npx esbuild assets/css/a11y.css --minify --outfile=assets/css/a11y.min.css
npx esbuild assets/js/a11y.js   --minify --target=es2017 --outfile=assets/js/a11y.min.js
```

### גרסאות

**כל שינוי בתבנית מקבל מספר גרסה חדש**, בשני מקומות: `Version` ב-`style.css` ו-`BIZMAX_VERSION` ב-`functions.php`.
מספר הגרסה מצורף לכתובות קבצי ה-CSS/JS (`?ver=`), כך שגרסה חדשה מבטיחה שהדפדפנים, LiteSpeed ו-Cloudflare יטענו את הקבצים המעודכנים.
תיקון קטן מעלה את הספרה האחרונה (1.1.0 ← 1.1.1); תכונה חדשה מעלה את האמצעית (1.1.1 ← 1.2.0).
